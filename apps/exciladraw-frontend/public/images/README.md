# Open country background

`open-country.webp` is a locally hosted, resized landscape photograph from
Unsplash: https://unsplash.com/photos/78A265wPiO4 (David Marcu).

Source image: https://images.unsplash.com/photo-1469474968028-56623f02e42e

License: https://unsplash.com/license — downloaded October 7, 2026.
The photo is credited on the authentication pages. It is used as a decorative
background, with page text, drawing accents, and contrast overlays implemented
separately. The image is served locally through Next Image; visitors do not
request the photo from Unsplash.
